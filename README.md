## Project Overview
This repository contains the hardware design, 3D models, Finite Element Analysis (FEA) reports, and technical documentation for a fully functional 4 Degree of Freedom (DOF) robotic arm. The project was developed starting from the Freenove base kit for mechatronic applications and evolved from a basic 2-DOF prototype built with scrap materials into a complete 3D-printed manipulator capable of lifting small loads.

## Hardware Components
The mechanical movement and control of the robotic arm rely on the following components:
*   3x SG90 9g micro servo motors (Scheduled for a v2 upgrade to MG996R servo motors due to the low critical load of the SG90s).
*   1x 28BYJ-48 unipolar stepper motor with ULN2003 driver board for azimuthal rotation.
*   3x Potentiometers for manual joint control.
*   1x Analog Joystick module for manual joint control.
*   Control board (Arduino-compatible architecture).

## 3D Modeling and Simulation (FEA)
The entire structure of the robotic arm was designed using SolidWorks and Autodesk Inventor. 

To validate the structural integrity of the 3D-printed parts, each individual component was tested using Finite Element Analysis (FEA) in Autodesk Inventor. The simulations were conducted applying an extreme load of 1 kg to the gripper. Since the ABS plastic used has a yield strength of 20 MPa, the structural analysis confirmed that the mechanical actuators will fail or stall long before the plastic undergoes any irreversible plastic deformation.

The FEA results highlighted a peak stress of approximately 60 MPa in certain conditions. As detailed in the technical report, this is a purely numerical artifact known as a stress singularity, caused by the absence of fillets on re-entrant corners in the CAD software, and does not pose a physical threat to the structure.

## Technical Documentation
A detailed technical report regarding the design, prototyping, and structural analysis of the robotic arm is included in this repository. The document was written and typeset in LaTeX to ensure a professional academic format and includes the mathematical treatment of the stress singularities encountered during the FEA.

## Repository Structure
*   /3D_Models: Contains all the individual CAD parts (SolidWorks and STEP formats) and the final assembly.
*   /FEA_Reports: Contains the PDF reports generated by Autodesk Inventor for the structural analysis of each component.
*   /Docs: Contains the LaTeX source code and the compiled PDF of the technical report.
